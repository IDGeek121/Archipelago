# Sonic Rchipelago Setup Guide

## Required Software

- Sonic R (PC, 2004). The PC 1998 release with [cheatfreak47's Sonic R Updater](https://github.com/cheatfreak47/SRUpdater) is also supported.
- [Sonic R Mod Loader](https://github.com/sonicretro/sonicr-mod-loader)
- [IDGeek's Sonic R Archipelago client (Sonic-Rchipelago)](https://github.com/IDGeek121/Sonic-Rchipelago)
- [IDGeek's Sonic R apworld](https://github.com/IDGeek121/Archipelago)
- [Archipelago](https://github.com/ArchipelagoMW/Archipelago/releases/latest)

## Installation

1. Install the apworld.
2. Download Sonic-Rchipelago and build from source (release soon... :p)
3. After building, copy the directory from mods/Sonic-Rchipelago into your Sonic R 2004 mods directory.
4. Open the Sonic R Mod Loader and enable/configure Sonic-Rchipelago.
